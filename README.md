# awecommerce

Monorepo for Awecommerce. The storefront and backoffice will live here later. The library is the only package for now.

| Package | Path | Role |
|---|---|---|
| `@awecommerce/service` | `packages/service` | Headless e-commerce library for Node.js and PostgreSQL |

Scripts at the repo root run the same command in `@awecommerce/service`. See [packages/service/README.md](packages/service/README.md) for how to install and use the library.
